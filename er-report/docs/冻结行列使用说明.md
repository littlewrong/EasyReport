# 冻结行列

在设计器中选中单元格并右键，使用“冻结至第 N 行”或“冻结至 X 列”。
冻结范围始终从第 1 行或 A 列开始，并包含当前行列；多选时以选区最下方、最右方为边界。
支持同时冻结行列，也可以分别取消或全部取消。

设置随报表模板保存，在设计器和网页预览中生效。预览使用报表区域内的滚动条；查询、自动刷新和物理分页切换后重新应用冻结。

## 稳定性限制

- 冻结行支持横向合并的大标题和纵向合并的多层表头。如果所选行切到纵向合并单元格，边界自动向下延伸，包含完整合并区域；右键菜单显示实际冻结到的行号。
- 冻结列使用相同规则：始终从 A 列开始，如果边界切到横向合并单元格，自动向右延伸到完整合并区域末尾。连锁相交的合并会继续补齐，菜单显示最终列号。
- 已冻结行列内部可以合并，但不能新建跨越已有冻结边界的合并；请先调整或取消对应方向的冻结。
- 冻结行不支持包含向下扩展的区域，冻结列不支持包含向右扩展的区域。左侧固定标识列随明细向下重复仍可冻结。
- 合并后被覆盖的非主格不参与扩展校验；拆分若会重新显露冻结行内的向下扩展或冻结列内的向右扩展单元格，需要先取消对应方向的冻结。
- 至少保留一行、一列作为可滚动区域。预览窗口过小时，无法给正文留出空间的方向会暂时不应用冻结，扩大窗口后重新计算。
- 插入、删除行列会调整冻结边界；冻结设置与这些编辑操作支持撤销、重做。
- 旧模板默认不冻结。补齐合并区域后仍须保留可滚动正文；例如整行合并标题覆盖 A 到末列时，不能只冻结其中几列，也不能冻结全部列。加载或预览发现对应方向动态扩展、运行时合并跨越边界、隐藏后没有剩余正文等不合法情况时，只取消受影响方向的冻结，不修改单元格内容和合并结构。
- 单栏分页预览支持冻结；后续页只有包含对应模板前缀（如重复表头）时才冻结。纸张多栏分页、打印和导出不应用网页冻结，打印的重复表头继续使用原有设置。

## 配置与验证

XML 根节点保存 `freeze-rows`、`freeze-columns` 两个非负整数，缺省为 `0`。
例如 `<easyreport freeze-rows="2" freeze-columns="1">` 表示冻结前两行及第一列。

后端按模板序号追踪展开前后的行列，只给普通 HTML 表格输出通过校验的冻结数量。
预览再次检查合并情况，根据实际尺寸设置固定位置，使用浏览器原生 sticky，不复制报表内容。

- 设计器规则与撤销测试：在 `easyreport-js` 下运行 `npm test`。
- 后端测试：父项目下运行 `mvn -pl easyreport-core -am test -Dtest=FreezeAreaTest -Dsurefire.failIfNoSpecifiedTests=false`。
- 浏览器回归：通过静态 HTTP 服务打开 `easyreport-js/test/preview-freeze.html`，点击“运行自动检查”。
